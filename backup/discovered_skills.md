# OpenClaw技能发现总结

## 主要技能库
1. **VoltAgent/awesome-openclaw-skills** - 最全面的技能库，包含近3000个社区构建的技能
2. **clawdbot-ai/awesome-openclaw-skills-zh** - 中文官方技能库，按场景分类整理

## 安装方法
1. **ClawHub CLI**: `npx clawhub@latest install <skill-slug>`
2. **手动安装**: 将技能文件夹复制到 `~/.openclaw/skills/`
3. **直接使用**: 将GitHub仓库链接粘贴到助手聊天中

## 推荐技能分类
### 生产力工具
- 日历管理 (Apple Calendar, Google Calendar)
- 邮件管理 (Email management)
- 任务管理 (Asana, Todoist)

### 开发工具
- 代码助手 (Coding agents)
- Git/GitHub工具
- 自动化工具

### 系统集成
- 浏览器自动化 (Browser automation)
- 文件管理 (File management)
- 系统监控 (System monitoring)

### AI增强
- Moltbook社交网络
- 搜索与研究工具
- 内容生成工具

## 安装建议
对于新用户，建议从简单的生产力工具开始，逐步添加更复杂的技能。
